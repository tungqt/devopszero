## 🎯 Mục tiêu khoá học
Khoá học này cung cấp nền tảng lập trình Python từ cơ bản đến nâng cao, tập trung vào việc tự động hoá các tác vụ IT và quản trị hệ thống. Đây là kiến thức cốt lõi (Phase 1) chuẩn bị cho các công việc DevOps phức tạp hơn.

Mục tiêu đầu ra:
1. Nắm vững cú pháp và cấu trúc dữ liệu của Python.
2. Sử dụng Python để tương tác với Hệ điều hành (đọc/ghi file, quản lý process).
3. Sử dụng Git/GitHub để quản lý mã nguồn.
4. Hiểu về Configuration Management và tự động hoá quy mô lớn.
